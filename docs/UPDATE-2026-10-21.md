# Current graphics source update — 21 October 2026

The working development card now uses **1280×720 Steam UI, Zink/NVIDIA,
composer-mode=3 and Gamescope --steam**. This is later than the historical
480p/CBrowserComposerGL profile. It remains a research prototype with serious
stability and compatibility limitations, not an everyday-use product.

## Frame path and CPU work

CEF/ANGLE issues GL through private Mesa24.2.8/Zink. Three DEVICE_LOCAL Vulkan
buffers are imported as GL PBOs; a shader writes pixels directly into GPU
memory. Ready/returned binary semaphores coordinate reuse. Gamescope copies
buffer→texture on the GPU, composites and presents through the Tegra LCD path.
The qualified CEF-child route avoids the former CPU glReadPixels, RGBA flip/
conversion and xcb_put_image upload. It is **not whole-stack zero-copy**:
GPU copies, CEF JavaScript/layout, IPC, driver submissions and game CPU
translation remain. High steamwebhelper CPU use does not prove llvmpipe.

## Changes included in the source tree

* M10K: do not synthetically pull the same raw transport buffer again when X11
  associates a wl_surface. One-shot ready signals cannot be consumed twice.
* M10K full unit15 provider closure: GLX override reassertion before reuse and
  Gallium external-wait batch tracking belong together with that consumer.
  The reduced Gamescope-only variant failed; do not substitute it silently.
* M10N: cursor orientation/position and USB input routing fixes.
* M10O: opt-in GAMESCOPE_TEGRA_EGLS_DISCARD_IDLE=1 avoids a two-second acquire
  for confirmed OLD/EMPTY frames while discarding stale EGLStream commits.
  Real FRAME waits, owner pins and wl_buffer.release are retained.
* Current wlserver/transport sources carry raw GPU-buffer delivery and tracing.

## Evidence and limits

User-confirmed 720p UI/sidebar navigation and HL2DM/FEX keyboard/mouse/gamepad
switching passed on the accepted card. Native SMB also passed ordinary input
and return-to-Steam checks. Presents/s are not physical/game FPS. Startup and
teardown EGL_BAD_STATE_KHR (0x321c), complete hangs and Windows panel/CEF-restore
lifecycle remain open in some paths. The Gamescope screenshot path is unsafe.
No new device test is performed by this publication. Beta1 boot is unqualified.
